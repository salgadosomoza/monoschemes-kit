# MonoSchemes Kit — archived

This repository is archived and kept as a historical reference for the original vanilla HTML, CSS, and JavaScript demos. It is no longer maintained. New component development, implementation, and documentation belong in **[MonoSchemes UI](https://github.com/salgadosomoza/monoschemes-ui)**.

## Current MonoSchemes sources

- **Design and design tokens:** [MonoSchemes in Figma](https://www.figma.com/design/XZ8yMM8VJihEwmyFaW6sCB/MonoSchemes-kit)
- **React components and public documentation:** [monoschemes-ui](https://github.com/salgadosomoza/monoschemes-ui)

The files in this repository are preserved for historical context only. Please do not use them as the current component or token contract.
